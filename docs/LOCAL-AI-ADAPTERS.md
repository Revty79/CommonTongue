# Production local AI adapters — Pass 7

Prerequisite: exact accepted Pass 6 closeout `3a2f3357f7ef3567d754943f6822fd06bdb1966f`, successful Actions run [37873843483](https://github.com/Revty79/CommonTongue/actions/runs/37873843483), verified before implementation.

`platform/local-ai` implements the neutral `SpeechRecognizer` and `Translator` contracts in `WhisperSpeechRecognizer` and `MadladTranslator`. `LocalAiSession` serializes their shared model owner. `CoreResourceSource` issues immutable, validated `ValidatedCoreResources` snapshots with version, role identities and an opaque storage token. `ResourceIntegrity` streams SHA-256 instead of allocating model-sized buffers. The adapters know neither filesystem layout nor acquisition source.

`platform/android-local-ai` supplies `AndroidResourceBindings`, `FileCoreResources`, `LocalAudioSource`, a constructor composition root (`LocalCapabilities`), the private `:local_ai` service, Messenger transport and production JNI. Future pack provisioning can replace the resource bindings without changing either capability. Future input controllers supply opaque audio references through `LocalAudioSource`; recognition is not coupled to PTT controls. A future iOS backend can implement the same neutral contracts.

The worker loads MADLAD first, then Whisper and keeps both resident, preserving Pass 5. A single executor serializes inference. Whisper context IDs and MADLAD model IDs are checked, monotonically allocated opaque IDs; neither is a native address. IDs remain inside the private worker. JNI uses real UTF-16/UTF-8 conversion and independently frees Rust strings. Rust owns tensors/config/tokenizer/model backing through the unchanged accepted registry and source. The wrapper only suppresses panic logging; no inference algorithm changes.

Latest request cancels the older coroutine. Cancellation/failure kills the same-UID worker and waits for binder death before reuse. This reclaims even blocking tensor kernels; it does not pretend they cooperate with coroutine cancellation. Next request revalidates resources and reloads in a fresh process. Explicit release, close and background transition reclaim the owner. Unconfirmed cleanup marks the session unusable instead of risking two owners. Generation/request matching rejects stale IPC events and results; post-operation coroutine checks reject stale native completion. Normal operation does not test radio/airplane state.

Recognition accepts locked English/Spanish only, translates no speech and does no automatic detection or vocabulary tuning. The input boundary currently accepts local mono 16 kHz PCM16 WAVs up to 31 seconds; it rejects other formats rather than silently resampling. Pass 8 will supply capture through the audio abstraction. Translation supports both directions, preserves canonical request identity, reports complete/partial honestly, and explicitly reports unsupported context, terminology, domain, regional preferences, critical-content verification and preservation policies. Required hints/REJECT requests fail before native work. Confidence stays unavailable, verification unverified; no notes or semantic verification are fabricated.

Only the debug `TestResources` helper has HTTP code. Its sole input is a committed immutable pack URL/hash, never speech or text. HTTPS redirects are restricted to GitHub's artifact hosts. It checks free storage, archive and every extracted file hash, exact bounded entry names/sizes, package identity and atomic private-directory installation. Interrupted/corrupt imports preserve the previous installation and never mark a partial installation ready. The downloaded archive/staging files are removed afterward. Models are not APK or Git assets. Release has no Internet permission. This code/dependency boundary is not an OS network sandbox: the debug app UID has Internet permission for acquisition, so the inference guard and native no-CURL build remain required.

Diagnostics use finite stages/failure codes and bounded timings/memory/exit reason numbers. They contain no audio, transcripts, translations, prompts, paths, exception messages, model handles or device/request identifiers. Native Whisper/ggml logging and Rust panic logging are suppressed. A throwing diagnostic sink cannot break inference. The controlled debug export contains only static check labels, match booleans/statuses and these diagnostics; fixed synthetic control phrases remain local assets, not exported human content.

The APK is an update for `com.commontongue.prototype.debug`, version code 8 / `0.7.0-pass7-dev`, using the existing local debug signer. It exposes one launcher. The old production voice check stays an internal route; its speech implementation is unchanged. Ordinary CI has a different debug key and its artifact cannot update this locally signed installation; use the published tester APK.

No Pass 8 visual design, conversation/PTT controller, VAD, context memory, pack store, accounts or additional language feature is included.
