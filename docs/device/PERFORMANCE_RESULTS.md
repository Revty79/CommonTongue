The user-reviewed v7 export reports microphone EN→ES/ES→EN and prerecorded completion with AudioTrack playback evidence. No warm median/p95, current inference peak or sustained battery/thermal result is inferred. Desktop figures remain context only; see [closeout](PASS_5_CLOSEOUT.md).

The app records monotonic launch-to-Activity-UI construction, model constructor load separately for translation and ASR, first-after-load and resident-turn index, ASR, translation, TTS synthesis, captured speech duration and release-to-audio separately. External app launch should also be measured with the coordinator's ADB launch timing; Activity construction alone is not full process launch.

Release time starts at the actual button-up handler, before microphone shutdown, WAV writing and worker IPC. Output uses synthesized PCM16 and AudioTrack. Audio start is estimated from a hardware timestamp, or playback-head observation, plus the first sample frame whose PCM amplitude exceeds 64/32768. Each result records its basis and leading-signal offset. This is not a calibrated microphone/loopback measurement of acoustic audibility; testers must confirm that translated speech is heard. TTS synthesis is separately measured, with synthesized files deleted after reading.

UI and inference processes each record process PSS, sampled RSS/high-water RSS where available, native heap, elapsed CPU time, total/available system RAM, battery percentage/temperature and Android thermal status. Worker/UI samples run approximately once per second; sampled peaks may miss transients and profiling overhead must be acknowledged. Summing PSS across simultaneous UI/worker samples approximates the research app footprint; the selected external/system TTS service process is additional and must be measured/labelled separately where obtainable. Phone-only export cannot inspect another app's private process memory; unavailable TTS memory remains unknown rather than being counted as zero.

Cold means freshly restarted application/models. The first translation after a load is explicitly tagged; later turns are warm while models remain resident. Cancellation/backgrounding discards resident models, so the next load starts another cold session. Do not pool text-only checks, WAV replay wall time and real microphone release-to-audio as one UX denominator. Replay playback is not an additional translation turn and cannot overwrite the original turn's timing.

For each device record pre-load RAM/storage, load outcome, first and warm EN→ES/ES→EN samples with counts/median/p95, ASR and translation timings, TTS synthesis/voice, release-to-audio estimate, process memory samples, battery/temperature before/after, thermal progression and errors. Record model-load/allocation failures, process disconnects and OS low-memory exit evidence when available. Confirm that the private native process disappears after cancellation/unload; observe retained UI memory after exit and subsequent reload.

The sustained S25 session targets 20–30 translated turns or 10–15 minutes. Record start/end battery and temperature, charging/USB-power state, thermal changes, memory progression and crashes. USB charging confounds battery-drain interpretation; do not convert a short or charging session into an hourly battery-life claim. Quiet-room success precedes controlled television/background speech, parked-car, outdoor noise or greater-distance trials. Separate ASR degradation from translation degradation.
